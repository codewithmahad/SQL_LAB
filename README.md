# SQL_LAB

SQL_LAB is my long-term workspace for learning, practicing, and mastering SQL through continuous study, experimentation, and problem solving.

Unlike a traditional project repository, this repository is designed to evolve over time. It serves as a personal knowledge base where I document new concepts, experiment with database features, solve technical interview problems, and continuously refine my understanding of SQL and relational databases.

The goal is not simply to collect solutions, but to build a structured reference that grows alongside my experience and remains useful throughout my software engineering career.

---

## Purpose

This repository exists to:

- Build a strong foundation in SQL and relational databases.
- Develop practical database problem-solving skills.
- Practice technical interview questions consistently.
- Explore PostgreSQL features and database concepts.
- Maintain a long-term reference for revision and future learning.
- Document continuous improvement over time.

---

## Repository Structure

```
SQL_LAB
│
├── assets
├── learning
├── practice
├── resources
├── README.md
└── .gitignore
```

### learning

Contains topic-based SQL examples, experiments, syntax demonstrations, and concept implementations as I progress through my learning roadmap.

New folders are created only when a topic is studied.

---

### practice

Contains solutions to SQL problems from coding platforms.

Current platforms include:

- LeetCode SQL 50
- HackerRank SQL

Each solution is maintained as an individual SQL file with the original problem reference where available.

---

### resources

Contains supporting material used throughout the learning process, including learning roadmaps and reference documents.

---

### assets

Contains images, diagrams, and other files used for documentation.
