# SQL_LAB

A long-term workspace for mastering SQL through continuous learning, practice, and database exploration.

This repository serves as a structured, living record of database engineering concepts, query optimization techniques, and daily problem-solving. It is divided into conceptual mastery based on an industry-standard database roadmap and active practice through technical challenges.

---

## 📂 Repository Architecture

The workspace is divided into two primary sections: Conceptual Learning and Applied Practice.

### 1. Conceptual Learning (`/01_Learning_Roadmap`)
This section contains syntax, experimental queries, and database design implementations following a structured progression.
* **Core Operations:** Basic SQL Syntax, Data Definition Language (DDL), and Data Manipulation Language (DML).
* **Relational Logic:** JOIN Queries, Subqueries, and Data Constraints.
* **Advanced Database Concepts:** Window Functions, Common Table Expressions, Stored Procedures, and Transactions.
* **Engineering & Tuning:** Query Analysis Techniques, Managing Indexes, and Performance Optimization.

*Note: The complete syllabus driving this progression is available in `roadmap.pdf`.*

### 2. Applied Practice 
This section contains optimized solutions to standard technical interview questions, demonstrating daily coding discipline.
* **`/02_LeetCode_50`**: Solutions for the LeetCode SQL 50 Interview Kit.
* **`/03_HackerRank_Challenges`**: Solutions for HackerRank SQL domain challenges ranging from Basic to Advanced.
